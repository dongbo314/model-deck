# Contributing

Thank you for improving Model Deck Core.

1. Discuss large changes in an issue before implementation.
2. Keep Core free of hardware-specific media runtimes; add those through capability contracts.
3. Never commit credentials, real provider endpoints, model weights, databases, logs or user media.
4. Run `npm run check`, `npm run build` and `npm run security:production` before opening a pull request.
5. Add tests for Windows and POSIX path behavior when changing file or process logic.
